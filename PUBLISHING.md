# Порядок ручной загрузки на GitHub

Репозиторий: https://github.com/rqLanter/ADKM-85-emulator

Новые файлы можно загружать по одному в таком порядке:

1. radiogram.py — настройки и план передачи.
2. test_radiogram.py — проверки планировщика.
3. radiogram_ui.py — окно редактора.
4. adkm85.py — подключение окна и общий вывод звука.
5. README.md — инструкция.
6. PUBLISHING.md — этот порядок публикации.

До шага 4 новые модули не меняют работу старой версии. Если в репозитории ещё
нет базового проекта, сначала загрузите learning.py, texts.txt, requirements.txt,
assets/adkm85.ico, adkm85.py и launcher.pyw как первую рабочую версию; кнопку
радиограмм используйте после загрузки обоих новых модулей.

Сборки release/, dist/, окружения, кэш, личная история и временные файлы в Git
не загружаются. Готовый EXE можно приложить к GitHub Release. Коммиты описывают
фактические изменения; даты и авторство не подменяются.
