# АДКМ-85 — тренажёр приёма Морзе

Настольный тренажёр для Windows: русская азбука Морзе, 150 учебных текстов,
случайные упражнения, подсветка сигнала, экзамен и статистика ошибок.
Работает локально, без регистрации и подключения к интернету.

В репозитории находятся исходники. Готовый EXE распространяется отдельно
или собирается по инструкции ниже; каталог `dist/` не включён в Git.

## Обычный запуск на Windows

Открой `release/ADKM85.exe` двойным щелчком. Python, pip и терминал не нужны.
EXE содержит программу, библиотеки, значок и базу всех 150 упражнений.

Для переноса на другой компьютер отправь `release/ADKM85.exe` или архив
`release/ADKM85-portable.zip`. Архив нужно сначала распаковать целиком.
В portable-папке рядом с EXE лежит `texts.txt`: можно исправлять буквы в нём.
Если рядом с EXE нет `texts.txt`, используется встроенная база.
Если внешний файл повреждён, программа покажет ошибку, чтобы правки не потерялись
за незаметным переключением на встроенную версию.

Можно создать обычный ярлык на `ADKM85.exe` и поместить его на рабочий стол.
После изменения исходников EXE необходимо пересобрать.

## Запуск исходников

При установленном Python и зависимостях `launcher.pyw` открывается без консоли
двойным щелчком, если расширение `.pyw` связано с Python.
При ошибке запуска он показывает сообщение и пытается сохранить подробности
в `%LOCALAPPDATA%/ADKM85/startup-error.log`.

Из терминала для разработки:

```powershell
python -m pip install -r requirements.txt
python adkm85.py
```

Выбери номер упражнения, нажми «Слушать / повторить» и введи услышанные буквы.
«Проверить ответ» показывает оригинал и сравнение: зелёные буквы верны, красные
отличаются, точка обозначает пропуск или лишнюю букву. Пробелы и регистр не учитываются.
Ошибки считаются по минимальному числу замен, пропусков и вставок.

- F5 — слушать или повторить.
- Esc — остановить передачу.
- Ctrl + Enter — проверить ответ.
- При выборе другого номера ответ очищается, оригинал снова скрывается.
- Скорость, тон и помехи применяются к следующему прослушиванию.

## Свободная тренировка и подсказка Морзе

Во вкладке «Тренировка» можно использовать весь русский алфавит или ввести
свои буквы, например `АОКМ`. Выбери длину (1, 5, 10 или 20) и нажми
«Новый набор». Пробелы и регистр в списке букв не учитываются, повторяющиеся
буквы не увеличивают вероятность их появления. «Слушать / повторить» играет
тот же набор; новый создаётся только кнопкой «Новый набор».

«Подсказка Морзе» показывает звучащую букву и её код. Точка или тире подсвечиваются
во время соответствующего звука; в паузах подсветка гаснет. Времена берутся из
тех же отсчётов, что и звук, а начало показа привязано к часам аудиоустройства.
При остановке или смене задания подсказка очищается.

В тренировке подсказка включается при переходе на вкладку. В режиме таблицы
по умолчанию выключена; её можно включить вручную. Она раскрывает текущую букву,
поэтому для проверки приёма исключительно на слух отключи эту галочку.
«Показать оригинал» независимо раскрывает всё задание.

## База текстов

В `texts.txt` перенесены 150 строк по 20 букв с шести фотографий печатных учебных таблиц.
Номер соответствует печатной таблице, пробелы в файле только разделяют группы
по пять букв для удобства сверки. В звуке между всеми буквами одинаковые паузы.
Показатель скорости — стандартная длительность точки `1.2 / WPM`;
реальное число русских букв в минуту зависит от состава строки.

Рукописные исправления не применены. № 76 и № 77 одинаковы и на фотографии.
В № 27, 47, 51, 63, 102 и 110 есть пометки поверх/около печатных букв;
эти строки полезно сверить с бумажным оригиналом. Особенно № 63, позиции 17–20:
они предварительно прочитаны как **ЗАБХ**, но перекрыты рукописным текстом.

Загрузчик сообщает об ошибках в базе (повтор номера, не 20 букв, неизвестный
символ), вместо того чтобы незаметно пропускать повреждённое упражнение.

## Проверка

```powershell
python -m unittest -v
```

Проверяются полнота базы, формат строк, выравнивание ответов с пропусками и
вставками, длительность и уровень звука, отмена генерации.

## Сборка EXE

Собирать на Windows с Python 3.11 или новее:

```powershell
python -m pip install -r requirements-build.txt
python build_windows.py
```

По умолчанию сборка создаёт только `release/ADKM85.exe`. Portable-папка и ZIP
создаются при явном запуске `python build_windows.py --portable`. Служебные каталоги
`build/` и `.build-cache/` при распространении не нужны. На компьютере получателя
Python не требуется. Зависимости сборки перечислены отдельно от зависимостей программы.

## Азбука, ошибки и экзамен

Кнопка «Азбука» открывает все русские буквы. Нажатие показывает код и проигрывает
его с подсветкой; скорость и тон берутся из основных настроек, помехи отключены.
Быстрый выбор другой буквы прерывает предыдущую. Во время активного экзамена
азбука недоступна.

«Мои ошибки» показывает путаницы (например С → Х), пропуски и лишние буквы,
отсортированные по частоте, а также последние 500 попыток. Счётчики ошибок
накапливаются без ограничения числа попыток. Кнопка «Тренировать проблемные
буквы» создаёт задание из до 10 букв, участвующих в самых частых ошибках,
включая обе стороны путаницы. Подсказка в таком задании отключена.

В статистику ошибок включаются только завершённые прослушивания с выключенными
подсказками. Если оригинал или подсказка открывались в течение попытки, она
сохраняется в истории с пометкой, но не увеличивает счётчики. Повторная проверка
и редактирование ответа не записывают одну попытку несколько раз. Проверка без
прослушивания не сохраняется. Для новой попытки выбери другое упражнение или
создай новый набор.

Во вкладке «Экзамен» выбирается случайный текст из таблицы. Номер скрыт до сдачи,
подсказки и повтор заблокированы. Ответ можно вводить во время передачи. После
сдачи ответ фиксируется и показываются текст, ошибки и оценка. Шкала приложения:
5 от 95%, 4 от 85%, 3 от 70%, иначе 2. Процент равен
`max(0, число букв − ошибки) / число букв × 100`; лишние буквы тоже штрафуются.
Это учебная шкала, а не официальный норматив. Пустой ответ можно сдать с оценкой 2.
Стоп, смена режима, новый экзамен или закрытие окна после начала экзамена
сохраняют незавершённую попытку без оценки и без влияния на статистику ошибок.

История хранится в `%LOCALAPPDATA%/ADKM85/progress.json`, поэтому остаётся после
обновления EXE. Интернет и учётная запись не нужны. При ошибке сохранения
показывается предупреждение. Повреждённая история не перезаписывается автоматически.


В «Мои ошибки» → «Последние попытки» можно выделить одну или несколько строк
(Ctrl / Shift) и нажать «Удалить выбранные» либо клавишу Delete. После подтверждения
попытки удаляются вместе с их вкладом в счётчики ошибок. Другие результаты,
включая накопленные данные старых попыток за пределами последних 500, сохраняются.
«Очистить всю историю» после отдельного подтверждения удаляет все записи и
полностью обнуляет накопленную статистику. Отменить удаление нельзя.


## Учебные радиограммы

Кнопка «Радиограмма» открывает независимый редактор; прежние тренировки,
азбука и экзамен остаются доступны. Выберите номер строки либо введите свой
текст. Пробелы и `|` задают группы в ручном режиме, перенос строки — границу строки.
В остальных режимах группировка строится из букв каждой строки.

Во вкладке «Текст и группы» выберите один из пяти режимов передачи, фиксированную
группировку (1–20), список размеров или ручные границы. Если список размеров
короче строки, остаток становится последней группой. Если длиннее — передача
блокируется с предупреждением. После изменения текста нажмите «Построить группы».
Каждой границе можно назначить свою паузу. Пустое поле означает общую настройку.
Сами учебные таблицы редактор не изменяет.

Во вкладках «Паузы» и «Начало и конец» доступны все интервалы в миллисекундах,
повторы, ЖЖЖ/К (или собственные сигналы), отдельные скорость и тон служебных
сигналов. По умолчанию служебные буквы не входят в ответ. Переключатель
«Проверять служебные сигналы» включает их в эталон; при повторах записывайте
все передачи последовательно. Разделитель `|` никогда не звучит.

Пресеты сложности — пользовательские учебные значения, не заводские нормативы.
Ручное изменение отображает «Пользовательский». Сохранение/загрузка JSON через
кнопки пресетов позволяет хранить сколько угодно собственных настроек.
Загрузка применяет значения по умолчанию для отсутствующих полей и проверяет
параметры. Внутренние интервалы, отличные от одной точки, разрешены только с
экспериментальным переключателем и предупреждением. «Восстановить стандартные
паузы» учитывает скорость и минимальные пределы полей.

План передачи строится отдельно от отображаемой строки. На границе выбирается
ровно одна пауза: индивидуальная, служебная, строковая, групповая, межбуквенная.
Классический режим игнорирует новую группировку при выборе межбуквенных пауз;
со старым генератором проведено побайтовое сравнение звука для учебной строки.
Видимость эталона: весь текст, только номер текущей группы, скрыт до проверки.
Состояние передачи и прогресс учитывают служебные сигналы, паузы и повторы.
Редактор проверяет последний полностью прослушанный план, а не изменённые после
прослушивания поля. При остановке проверка незавершённой передачи недоступна.
Результаты отдельного редактора пока не записываются в общую историю попыток.

Ограничения ресурсов: до 20 повторов, до 2000 букв в итоговом эталоне и до 20 минут
звука в памяти. Эти ограничения не привязывают собственные радиограммы к 20 буквам.


## Общие настройки передачи

В окне «Радиограмма» нажмите «Применить к приложению», чтобы использовать
настроенные паузы, группы, скорость и тон в основной таблице или экзамене.
Исходная строка таблицы при этом сохраняется. Для основных упражнений и экзамена
используется одна передача, а служебные сигналы не включаются в ответ.
Сами поля отдельного редактора продолжают поддерживать повторы и собственный текст.

В главном окне «Стандартный Морзе» воспроизводит прежние интервалы (1 точка внутри
буквы и 3 точки между буквами). Вариант «Радиограмма» использует применённые паузы.
Галочки «ЖЖЖ в начале» и «К в конце» работают независимо от этих вариантов.
В тренировке служебные сигналы также можно включать и выключать этими галочками;
в эталон ответа они не входят. В экзамене их состояние фиксируется при запуске.
